## Правила ведения

- Новое требование = новый номер в блоке-сотне по смыслу + строка в файле блока; при необходимости — новый файл блока.
- Требование меняет статус только вместе с CR, который это реализовал (ссылка на CR в тексте).
- «⬜ задел» — осознанно отложенное, не «забытое»: помечать C-приоритетом.
