# FR-9xx — BYOK: свои LLM-провайдеры и ключи

> Блок требований: роутер LLM-вызовов, конфигурация по ролям, безопасное хранение ключей,
> provenance моделей, UI настроек. Реализация — [CR-007](../cr/CR-007-byok-mvp.md).
> Связанное: [ADR-012](../adr/ADR-012-byok-llm-router.md)

- **FR-901 (M) ✅ (CR-007)** Роутер LLM-вызовов с адаптерами: `zai` (дефолт — поведение без
  конфигурации не отличается от текущего) и `openai-compatible` (baseUrl + apiKey + model;
  покрывает OpenAI, DeepSeek, OpenRouter, Groq, Ollama, LM Studio, vLLM). extractJson/repairJson,
  таймауты и ретраи — провайдер-агностичны, над адаптерами.
- **FR-902 (M) ✅ (CR-007)** Конфигурация по ролям: planner / executor / supervisor / decider —
  каждая роль резолвится по цепочке «роль → дефолт → zai»; параметры: adapter, baseUrl, model,
  apiKey, temperature. Для headless — env-переменные `AVIZIS_LLM_*` (бутстрап без файла).
- **FR-903 (M) ✅ (CR-007)** Безопасность ключей: хранение только в серверном
  `data/llm-config.json` (chmod 600); API чтения возвращает маску (первые 3 + последние 4
  симв.), полный ключ не возвращается никогда; сохранение сопровождается валидацией пробным
  запросом; **ключи не появляются в `runs.json`, снапшотах, событиях, логах и экспортах** —
  гарантируется автоматическим тестом (поиск строки ключа в артефактах прогона).
- **FR-904 (M) ✅ (CR-007)** Provenance моделей: `RunSnapshot.llm = {role → {adapter, model}}`
  (без ключей) при старте прогона; `node.llm = {adapter, model}` у каждого LLM-узла; запись в
  журнал при старте планирования («Планировщик: openai-compatible · gpt-4o»); бейдж модели в
  инспекторе узла; индикатор активного провайдера в тулбаре; секция моделей в MD-отчёте. Replay
  показывает, какой моделью получен каждый узел.
- **FR-905 (M) ✅ (CR-007)** UI настроек: модалка (пресет провайдера, baseUrl, модель, ключ с
  show/hide, кнопка «Проверить подключение» с результатом, per-role overrides в расширенном
  режиме, сохранение); индикатор активного провайдера в тулбаре запуска.
- **FR-906 (S) ✅ (CR-007)** Диагностика ошибок провайдера: структурные ошибки (401 — неверный
  ключ, 404 — неверный baseUrl, недоступность, таймаут) отображаются человекочитаемо в модалке
  настроек и попадают в журнал прогона; LLM-прогон не падает молча — узел завершается ошибкой
  с причиной.
- **FR-907 (C) ⬜→✅** Стриминг ответов исполнителя — ✅ (CR-016: node:stream-снапшоты
  поверх обоих адаптеров, ADR-023; демо-симуляция). Нативные адаптеры anthropic / google-gemini —
  ✅ (CR-017: собственные протоколы Messages API / generateContent, ADR-024: пресеты настроек,
  probe-валидация, стриминг, ключи в x-api-key/x-goog-api-key; мок-провайдеры для тестов без
  реальных ключей).
  Счётчики токенов и стоимости выделены в FR-605/FR-908
  и реализованы (CR-009/CR-011).
- **FR-908 (M) ✅ (CR-011)** Стоимость прогонов в USD поверх токенов, **динамический прайсинг**:
  цены подтягиваются в рантайме с OpenRouter (`/api/v1/models`) и из открытого каталога LiteLLM
  (ничего не захардкожено), кэшируются на диске (TTL 24 ч, `AVIZIS_PRICING_TTL_HOURS`,
  `AVIZIS_PRICING_DISABLED=1` — только ручные); ручной override — `pricing.models` в конфиге
  (приоритет выше каталогов; z-ai SDK/Ollama/свой тариф), редактируется в UI и руками.
  Стоимость считается движком на момент вызова, едет событием `llm:usage` (`costUsd`,
  `priceSource`) → снапшот (итог + по ролям + `unpricedCalls`) → узлы → fold (live и replay).
  UI: чип тулбара `≈$…`, тултип по ролям, инспектор узла, журнал (`· ≈$…`), MD-отчёт (колонки
  «Стоимость» + provenance прайсов: источник/модели/свежесть/без оценки), блок «Прайсинг
  моделей» в настройках с обновлением по кнопке. Неизвестная цена — честное «не оценено»,
  а не выдуманное число. Связанное: [ADR-016](../adr/ADR-016-dynamic-pricing-cost-audit.md).
- **FR-910 (M) ✅ (CR-012)** **Конвертация валюты стоимости**: курсы подтягиваются в рантайме из
  цепочки источников (приоритет по каждой валюте): ручной `currency.rates` в конфиге (детерминизм,
  офлайн, редактирование в UI) → официальный XML ЦБ РФ (windows-1251, кросс-курсы через рубль с
  учётом Nominal, `asOf` = дата реестра) → JSON-зеркало cbr-xml-daily → open.er-api (независимая
  точка, ~160 валют). Куррируемый список из 15 валют; кэш на диске (TTL 6 ч,
  `AVIZIS_CURRENCY_TTL_HOURS`, `AVIZIS_CURRENCY_DISABLED=1` — только ручной). **Базис аудита — USD
  без изменений**: события/снапшоты/runs.json не зависят от курса; конвертация только на
  отображении — чип тулбара («· ≈$0,0027 · ₽0,263»), тултип по ролям, инспектор узла, MD-отчёт
  (колонки + блок «Курс конвертации» с источником и датой котировки). Селектор валюты в
  настройках (дефолт ₽), выбор в `localStorage`. Офлайн → стоимость остаётся в USD. Связанное:
  [ADR-019](../adr/ADR-019-currency-conversion.md).
- **FR-911 (M) ✅ (CR-013)** **Гейт OpenRouter «agentic harnesses»**: free-эндпоинты, доступные
  только агентным харнесам (пример — `thinkingmachines/inkling:free`), проходят автоматически —
  общий клиент openai-compatible (`openai-client.ts`: адаптер llm.ts + проба валидации настроек)
  детектит маркер гейта в ошибке (403-тело или `error` внутри 200-ответа), повторяет запрос с
  минимальным набором tools `submit_final_answer` (без `tool_choice` — free-варианты его не
  поддерживают) и кэширует решение per `(baseUrl|model)` до рестарта движка. Ответ-`tool_calls`
  разворачивается в текст (`extractMessageContent`). 4xx-ошибки ключа/доступа/пути —
  `NonRetryableProviderError`: ретраи пропускаются, ошибка мгновенная (408/429/5xx — транзиентны).
  Связанное: [ADR-020](../adr/ADR-020-openrouter-agentic-gate.md).
