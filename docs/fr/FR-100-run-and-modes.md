# FR-1xx — Запуск и режимы

> Блок требований: запуск прогона и режимы движка. Все ✅ реализованы и проверены.
> Связанное: [ADR-002](../adr/ADR-002-socket-io-mini-service.md), [ADR-007](../adr/ADR-007-auto-manual-decision-modes.md), [ADR-008](../adr/ADR-008-demo-llm-dual-mode.md)

- **FR-101 (M) ✅** Запуск прогона по задаче пользователя: `run:start {task, mode, decisionMode}`.
- **FR-102 (M) ✅** Режим `demo` — детерминированный сценарий без LLM: валидация →
  развилка (3 стратегии) → ветка → итог; выходы зависят от выбранной стратегии.
- **FR-103 (M) ✅** Режим `llm` — план/исполнение/адаптация/решения генерируются
  z-ai-web-dev-sdk (3 LLM-роли + decider), JSON ремонтируется и валидируется.
- **FR-104 (S) ✅** Выбор режима решений при старте прогона (вручную / авто) из панели истории.
- **FR-105 (M) ✅** Управление прогоном: пауза / резюм / стоп; пауза уважается в фазе
  рассуждения агента; статус пушится мгновенно.
