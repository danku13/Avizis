# FR-3xx — Инспектор узла

> Блок требований: модальный инспектор узла. Все ✅ реализованы и проверены.
> Связанное: [ADR-005](../adr/ADR-005-inspector-modal-50vw.md), [CR-002](../cr/CR-002-fullwidth-reactflow-inspector-modal.md), [CR-005](../cr/CR-005-full-texts-and-docs-restructure.md)

- **FR-301 (M) ✅** Открывается кликом по узлу как модалка шириной ≥50% экрана
  (sm:55vw / lg:58vw / xl:64vw), высота 86dvh, на мобиле ~92vw; закрытие Esc/фон.
- **FR-302 (M) ✅** Содержимое: описание, вход, выход, причина динамического узла, ошибка,
  тайминги (start/finish/duration), зависимости (кликабельные ссылки-чипы), бейджи
  «развилка · N вариантов» / «ветка X» / «изм.» / счётчик запусков.
- **FR-303 (M) ✅** Вмешательство из инспектора: переопределить результат узла (output)
  → потомки пересчитываются (пометка «изм.», runs++), погашенные ветки не воскресают;
  повторить узел (retry) при ошибке.
- **FR-304 (S) ✅** Для узла-развилки: вопрос, все варианты с выделением выбранного,
  «Решение принял: агент | пользователь», блок рассуждения/обоснования, кнопка
  «Открыть выбор варианта» (если развилка ещё ожидает).
- **FR-309 (M) ✅** (CR-005) Полные тексты без обрезки: «Причина добавления», «Вход» и
  «Выход» выводятся целиком — движок не усекает данные узла (обрезка «…» в `buildInput`
  убрана; лимиты LLM-полей подняты до 800 симв.), в вёрстке сняты капы высоты
  (`max-h-52` / `max-h-[38vh]`) — длинные тексты прокручиваются на уровне колонки модалки;
  обрезка остаётся только в компактных строках журнала событий.
