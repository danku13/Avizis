# FR-7xx — Нефункциональные требования

> Блок требований: вёрстка, производительность, качество. 7 ✅ + 1 ⬜ (задел).
> Связанное: [CR-002](../cr/CR-002-fullwidth-reactflow-inspector-modal.md)

- **FR-701 (M) ✅** Вёрстка на всю ширину экрана: app-shell без прокрутки на десктопе
  (h-dvh + overflow-hidden), граф занимает всё доступное пространство; правая колонка
  инспектора убрана (модалка).
- **FR-702 (M) ✅** Мобильная адаптация 390px: колонки в стек, канва ≥380px, модалки
  ~92vw, без горизонтального скролла.
- **FR-703 (M) ✅** Чистая консоль: 0 ошибок / 0 предупреждений; lint без замечаний.
- **FR-704 (S) ✅** Тёмная тема целиком (React Flow Controls/MiniMap/атрибуция стилизованы).
- **FR-705 (C) ⬜** (задел) Мультивариантные прогоны «A/B веток» параллельно — вне прототипа.
- **FR-706 (M) ✅ (CR-009)** Светлая тема: переключатель в шапке (Sun/Moon), выбор в
  localStorage `tacg-theme`, применяется до гидрации bootstrap-скриптом (без всплеска),
  переживает перезагрузку; дефолт — тёмная. Все TACG-поверхности — light-варианты (фоны,
  тексты, бордеры, акценты 600↔300); React Flow Controls/MiniMap/атрибуция/скроллбары и
  базовые цвета рёбер/фона канвы — от темы.
- **FR-707 (M) ✅ (CR-009)** Цветовая кодировка различает семантику: «добавлено динамически» —
  violet (холодный), «развилка решения» — amber («ваш ход», тёплый) — максимально удалённые
  оттенки между собой и от статусных цветов; «ожидает» — нейтральный цинк (не путается с
  развилками); обновлены легенда, статусные точки, рёбра ветвей (amber-пунктир до выбора),
  минимапа и акценты всех модалок/журнала.
- **FR-708 (M) ✅ (CR-010)** Эффективное использование вертикали: журнал событий сворачиваемый
  (клик по строке-заголовку с chevron, 260px ↔ 44px, плавная анимация, `aria-expanded`),
  выбор в localStorage `tacg-log-collapsed` переживает перезагрузку (SSR-снимок согласован),
  свёрнутый вид показывает live/кадр, счётчик записей и превью последней записи; шапка — одна
  компактная строка h-11 (~61px → 45px): подзаголовок убран, статус движка и тема компактные,
  чип LLM/настроек BYOK перенесён туда из тулбара (глобальная настройка); свёрнутый журнал
  отдаёт графу 216px.
- **FR-709 (M) ✅ (CR-014)** Автообновление и portable без установки (ADR-021): приложение тихо
  проверяет GitHub `releases/latest` при старте и по кнопке в футере; при новой версии — тост
  «Доступна версия vX.Y.Z» с кнопкой «Обновить»; применение — скачивание портативного zip с
  прогрессом (МБ + %) → подмена файлов рядом с exe (движок → прочее → оболочка) → автоперезапуск;
  история/ключи/настройки в каталоге ОС не трогаются; один механизм для установленной (NSIS) и
  portable-версии (zip с README запускается без установки); ошибки — понятными тостами, бейдж в
  футере показывает состояние; контракт обновления тестируется в браузере через `?update-mock=1`.
- **FR-710 (M) ✅ (CR-015)** Двуязычность RU/EN (ADR-022): интерфейс — переключатель в шапке
  (RU ⇄ EN), выбор в localStorage `tacg-locale` + `<html lang>`, детект по языку браузера,
  RU-пререндер без гидратационных рассинхронов; весь словарь — плоские ключи с фолбэком
  en → ru → ключ и интерполяцией `{параметр}`. Язык прогона — независим от UI и определяется
  задачей (кириллица → ru, иначе → en): контент LLM (системные промпты ×4 ролей + суффикс
  «Respond in English only»), демо-сценарии (EN-зеркало обоих сценариев: планы, развилки,
  обоснования, скриптованные выводы), журналы/статусы/итоговый summary/ошибки управления —
  L(lang, ru, en); пустая задача демо — дефолт на языке UI (locale в handshake socket.io);
  поле задачи следует за языком интерфейса, пока пользователь не начал ввод; демо-видео —
  MP4 с переключаемыми дорожками субтитров EN (default) / RU + превью-GIF.
