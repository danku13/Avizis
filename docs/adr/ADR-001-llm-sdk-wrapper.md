# ADR-001: LLM через z-ai-web-dev-sdk с repair-парсером JSON

> Тип: ADR · Статус: принято · Контекст: старт сессии · Связанное: [CR-001](../cr/CR-001-prototype.md), [ADR-008](./ADR-008-demo-llm-dual-mode.md)

**Контекст.** Прототип создан специально для тестирования `z-ai-web-dev-sdk`. Движку нужны
три LLM-роли (планировщик / исполнитель / супервайзер + позже decider), ответы приходят в JSON.
Наблюдаемые проблемы: обрывы массивов, висячие запятые, «reasoning» внутри массива nodes.

**Решение.** Единая обёртка-синглтон `llm.ts`: таймауты, ретраи, `repairJson()` (достраивает
незакрытые массивы/скобки, убирает висячие запятые), валидация схемы ответа с повтором запроса.

**Альтернативы.** Сырые вызовы SDK без обёртки — быстро ломаются на кривом JSON;
стриминговый парсинг — избыточен для прототипа.

**Последствия.** LLM-режим устойчив (тест `test-avizis-llm` пройден); любую новую роль
(decider в ADR-007) добавляем через системный промпт без изменения инфраструктуры.
