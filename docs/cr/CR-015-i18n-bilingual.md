# CR-015 — Двуязычность RU/EN и демо-видео

> Дата: 2026-10-13 · Статус: ✅ завершено в v0.12.0 · ADR: [ADR-022](../adr/ADR-022-bilingual-i18n.md) ·
> FR: [FR-710](../fr/FR-700-nfr.md)

## Запрос

> Формулировка восстановлена по артефактам оборванной сессии (контекст утерян, коммит 48f6880):
> «сделать продукт двуязычным — русский/английский интерфейс и англоязычные прогоны агента;
> записать демо-видео для показа».

## Что сделано

### Оборванная сессия (коммит 48f6880, доведено этой сессией)

1. **Словари и переключатель**: `i18n-ru.ts`/`i18n-en.ts` (~430 ключей), стор с RU-пререндером
   и персистом `tacg-locale`, кнопка RU ⇄ EN в шапке, `<html lang>` синхронизируется; переведены
   все TACG-компоненты (тулбар, история, инспектор, модалки настроек/развилки, журнал, бейдж
   обновления, отчёт MD).
2. **Системные промпты EN** для 4 ролей + `promptLangSuffix` («Respond in English only…»);
   язык прогона = `detectLang(задача)`.
3. **Демо-видео** (4:06): запись чанками по 20с (agent-browser recorder, буфер ~3МБ) → монтаж
   ffmpeg по сегментам (скорости 1.0–1.4, x264, crf 20) → EN-видео + SRT-субтитры RU/EN.

### Доделано этой сессией (v0.12.0)

4. **Демо-контент EN**: `demo-i18n-en.ts` — EN-зеркало обоих сценариев (план, развилка стратегии
   проверки, три эмерджентных уточнения «Напиши пост», скриптованные выводы всех узлов, авто-
   решения, заметки понимания); все экспорты `demo.ts` параметризованы `lang` и диспетчеризуются
   движком по `rt.lang`. До фикса: EN-задача в демо-режиме давала русский граф.
5. **Хвосты движка**: локализованы журналы развилок (предложение/режим/решение/гашение веток),
   адаптаций и «лимиты», эмерджентные развилки, причины ошибок статусов, итоговый summary
   (`Готово за…` / `Done in…`), сводка токенов прогона, ошибки управления (override/retry/
   decision), префикс пересчёта, кавычки-ёлочки → языкозависимые.
6. **Пустая задача демо** — дефолт на языке UI: locale уезжает в handshake socket.io →
   `engine.start(..., uiLang)`.
7. **Поле задачи следует за языком UI** (userTask=null → локализованный пример при рендере,
   без эффекта под ESL-правило setState-in-effect); было: EN-интерфейс + русское поле.
8. **Видео финализировано**: `tacg-demo.mp4` = видео + soft-subs `eng` (default) + `rus`
   (mov_text, language-теги); `.srt` остаются рядом; `tacg-demo-preview.gif` (12с, 640px,
   палитровый) для README.
9. **Тест-инфраструктура**: гейт-тест OpenRouter восстанавливает конфиг движка через
   `llm:config:save` (раньше — прямой файл-запись, и кэш движка оставался с мок-адресом →
   следующий LLM-прогон ловил ConnectionRefused).

## Результат (проверяемо)

- Регрессии: decision ✅ все сценарии; llm-auto ✅ (7 узлов, решение агентом); updater 5/5;
  openrouter-gate 14/14 (конфиг после теста = zai); byok 13/13; clarity 17/17; usage 13/13;
  truncation 31/31; pricing 26/26; currency 26/26. `tsc` — новых ошибок 0 (база graph-canvas/
  xyflow без изменений), `eslint` — чисто.
- EN-прогон демо через socket: план «Data and context collection → … → Result assembly»,
   адаптация «Data validation v2», развилка и авто-решение — английские; completed 100%.
- RU-прогон демо: «Сбор данных и контекста → …», «Валидация данных v2» — русские (регресс нет).
- E2E браузер (статика :8200 + движок :3003): EN по умолчанию (en-US браузер) — UI, поле задачи,
  граф, журнал («⎇ Decision made (by the user): … — branch activated», «✓ Task completed in
  27.1 s»), модалка развилки — EN; переключение RU → UI+задача+граф RU; локаль переживает
  reload; мобильная 390px без hscroll; консоль 0 ошибок/0 сообщений.
- Видео: `ffprobe tacg-demo.mp4` → h264 + mov_text(eng, default) + mov_text(rus), 245.9с;
  GIF 12.0с / 472КБ. Скриншоты: `scripts/tacg-e2e-{ru-default,en-fixed}.png`,
  `tacg-i18n-{en-final,mobile}.png`.
