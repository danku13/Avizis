# CR-011 — Стоимость прогонов в деньгах (динамический прайсинг) + исполняемые файлы стенда

> Сессия 2026-10-12 · Task ID 14 · Связанное: [ADR-016](../adr/ADR-016-dynamic-pricing-cost-audit.md),
> [ADR-017](../adr/ADR-017-single-file-executable.md), [FR-908](../fr/FR-900-byok.md)

## Мотивация (цитаты запроса)

> «добавить стоимость в деньгах в плюс к количеству токенов токенов на базе прайсинга моделей
> (стоимости должны быть динамическими получаемыми от провайдеров, а не захардкоженными)»

> «и сразу главный вопрос - как минимальными усилиями обернуть сервис в windows / macos
> executable для запуска "одним файлом" без разёртывания инфраструктуры»

## Что сделано

**1. Динамический прайсинг (`mini-services/tacg-agent/pricing.ts` — новый модуль).** Цены не
захардкожены: подтягиваются в рантайме с OpenRouter (`/api/v1/models`, 432 модели на момент
прогона) и из открытого каталога LiteLLM (3134 модели), кэшируются на диске
(`data/pricing-cache.json`), TTL 24 ч (`TACG_PRICING_TTL_HOURS`), офлайн-устойчиво,
`TACG_PRICING_DISABLED=1` — только ручные цены. Ручной override — секция `pricing.models`
в `llm-config.json` (приоритет выше каталогов; для z-ai SDK/Ollama/своих тарифов). Разрешение
модели: точное совпадение → суффикс `:free` → базовый id → уникальный вендор OpenRouter;
неоднозначность → честное «нет цены».

**2. Стоимость в конвейере аудита.** `engine.addUsage` считает `costUsd` (in/1e6 × priceIn +
out/1e6 × priceOut) и расширяет событие `llm:usage` полями `adapter`/`model`/`costUsd`/
`priceSource` (старые прогоны совместимы); `RunUsage` — `costUsd`, `byRole[role].costUsd`,
`unpricedCalls`; `node.usage.costUsd`; `foldEvents` — те же суммы для live и replay. Журнал:
`· ≈$0,00045` у шагов, `· ≈$0,00315` в финальной записи и summary. `fmtUsd` —
`$1,23`/`$0,0123`/`$0,00045` (3 значащих до $1, запятая).

**3. UI стоимости.** Чип тулбара `↑ 700 · ↓ 140 · 7 вызов. · ≈$0,00315` + тултип по ролям
(при отсутствии цены — «не оценена, N вызов. без прайса»); инспектор узла
`Токены: ↑ 100 · ↓ 20 · ≈$0,00045`; MD-отчёт — строка «Стоимость LLM», колонки «Стоимость»
в таблицах ролей и графа, блок provenance прайсов (источники/свежесть/без оценки); модалка
настроек — блок «Прайсинг моделей (динамический)» со статусом источников и кнопкой
«Обновить прайсы», поля «Цена модели за 1M токенов, $» (override текущей модели, префилл
из конфига, per-key merge при сохранении).

**4. Исполняемые файлы (ADR-017).** `scripts/build-executables.sh` — кросс-компиляция движка
в один файл: `bun build --compile --target=bun-{windows-x64,darwin-x64,darwin-arm64,linux-x64}`
(62–95 МБ, рантайм+socket.io+адаптеры внутри). `data-dir.ts` — портативные данные: в бинарнике
`import.meta.dir` = `/$bunfs/root` (read-only), поэтому `data/` создаётся рядом с exe
(проверено: бинарник поднял 20 прогонов из `dist/data/runs.json`). Рецепт «одного файла совсем»
(статический экспорт Next.js + встраивание ассетов в тот же exe) зафиксирован в ADR-017 как
следующий уровень; ответ на вопрос пользователя — в сессии и ADR.

## Результат (верифицировано)

- `scripts/test-tacg-pricing.ts` (новый) — **26/26 ✅**: unit (парсинг OpenRouter/LiteLLM,
  приоритет manual, нормализация `:free`/базовый id, неоднозначность → null, арифметика,
  `fmtUsd`, офлайн — кэш жив, сброс памяти → подъём с диска) + fold (costUsd по ролям/узлам,
  unpricedCalls, старый формат событий) + интеграция с моком (7 вызовов → `costUsd=0.00315`,
  роли 0.00045/0.00135/0.0009/0.00045; события с provenance и `priceSource='manual'`; узлы
  n1/dec1/ba1/nfin по $0,00045; журнал `· ≈$0,00045` и итог `≈$0,00315`; summary; fold=движок;
  runs.json без ключа; `pricing:refresh` по сокету).
- Регрессии: usage 13/13, byok 13/13, truncation 31/31, clarity 17/17, decision — все сценарии;
  tsc = база (3 новых — того же класса, что в test-tacg-usage); lint чист.
- E2E agent-browser: прогон через UI с ценой 2.5/10 за 1M → чип `≈$0,00315`; журнал;
  инспектор `↑ 100 · ↓ 20 · ≈$0,00045`; MD (перехват Blob): «Стоимость LLM: ≈ $0,00315
  (динамический прайсинг)», «Итого | 7 | ↑ 700 | ↓ 140 | ≈ $0,00315», колонка «Стоимость»
  узлов, «Прайсинг (динамический, без захардкоженных цен)… вручную (конфиг): 1»; настройки:
  блок источников с датами, «Обновить прайсы» → тост «Прайсы моделей обновлены», префилл
  полей цены 2.5/10; консоль 0 ошибок; мобильная 390×844 без hscroll; VLM-проверка скриншотов —
  дефектов нет. Дефолты восстановлены (zai, файл конфига чистый, мок остановлен).
- Сборка: 4 бинарника в `mini-services/tacg-agent/dist/` (gitignored), linux-вариант запущен —
  socket.io отвечает, история из `dist/data`, кэш прайсов рядом с exe.
