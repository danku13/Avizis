# CR-006: Снятие лимитов эмерджентных вопросов и жёстких объёмов

> Task ID: 7 · Формат: мотивация (цитата) → изменения → результат.

**Мотивация (цитата запроса).** «1. не ограничивай количество эмерджентных вопросов. 2. не
ограничивай объём входов, выходов и обоснований жёстко, но в промтах для агентов учитывай что
не надо раздувать контекст и следить за полезностью информации. выведи мне в чат все ограничения,
которые ты применил при работе сервиса»

**Изменения.**
- `engine.ts` — лимиты сняты: удалены проверки `rt.dynamicAdded >= 2`, `dynamic-узлов >= 3`,
  `rt.emergentAdded < 2`; `askAllowed = !hasOpenDecision` (последовательность вопросов, не количество).
- `engine.ts` — объёмные срезы сняты: `.slice(0, 500)` (task), `.slice(0, 800)` ×11
  (description/question/rationale/reason/reasoning), `.slice(0, 4000)` (override output).
  Ярлыки title/label ≤60 и заголовок вопроса ≤40 сохранены (идентификация узлов на канве).
- Промпты — дисциплина вместо капов: EXECUTOR_SYS «до 120 слов» → «минимально достаточный объём,
  без воды и повторов»; супервайзеру добавлено «количество вопросов не ограничено, но каждый
  обязан быть полезным: не дублируй закрытые»; decider «обоснование в 1–2 предложениях» →
  «краткое, но исчерпывающее обоснование без воды».
- Компакция промптов сохранена (12 000 симв. вход исполнителя; 400/2000 — контекст супервайзера),
  усечения строк журнала сохранены (полные тексты — в инспекторе).
- UI: label вариантов в инспекторе и модалке выбора — перенос (`break-words`) вместо `truncate`.
- Полный реестр применённых ограничений выведен пользователю в чат (по прямому запросу) —
  зафиксирован в [ADR-011](../adr/ADR-011-unbounded-questions-soft-volumes.md).

**Результат.** `tsc --noEmit` мини-сервиса — чисто (единственное — Bun-специфичный `import.meta.dir`);
`test-avizis-decision` — все сценарии зелёные; `test-avizis-clarity` — 17/17; новый скрипт
`scripts/test-avizis-llm-auto.ts` (LLM + decisionMode=auto): полный прогон за 28.7 с, 2 развилки
закрыты агентом с обоснованиями, выходы узлов до 1314 симв. — прежний кап 800 снят.
Ошибки tsc в `src/` (8 шт., graph-canvas.tsx, типизация React Flow) — преждесуществующие,
проверено на коде до правок (git stash): те же 8.
