# CR-005 — Полные тексты инспектора + реструктуризация /docs

> Тип: CR · Task ID: 6 · Связанное: [ADR-005](../adr/ADR-005-inspector-modal-50vw.md), [FR-309](../fr/FR-300-node-inspector.md)

**Мотивация.** «исправь проблему что тексты в Причина добавления, Вход и Выход не выводятся
полностью, а просто обрезаются многоточием. реструктурируй /docs так чтобы под каждый тип
документа была своя папка, в которой будет индекс и каждый документ будет лежать отдельно,
для наиболее эффективного структурирования для агентной разработки».

**Диагностика.** Обрезка «…» оказалась на трёх уровнях:
1. данные движка: `buildInput` усекал выходы зависимостей до 260 симв. с «…» — в сохранённых
   прогонах 49 узлов с обрезанным «Входом»;
2. данные LLM-полей: причина добавления (reason) и rationale/question жёстко резались на
   240/320/300 симв.;
3. вёрстка инспектора: `max-h-52` на «Входе» и `max-h-[38vh]` на «Выходе» прятали хвост
   текста во внутренней прокрутке маленького блока.

**Изменения.**
- `engine.ts`:
  - `buildInput` хранит ПОЛНЫЕ выходы зависимостей (никакой обрезки) — «Вход» узла
    теперь данные инспектора, а не усечённый промпт;
  - обрезка промптов вынесена туда, где она и должна жить: `llmExecute` — щедрый
    предохранитель 12 000 симв., супервайзер видит результат шага до 2000 симв. (было 300);
  - лимиты LLM-полей подняты: reason/description/question/rationale/reasoning
    240–400 → 800 симв. (и у планировщика через sanitizePlan тоже).
- `node-inspector.tsx`: сняты капы высоты `max-h-52` / `max-h-[38vh]` с «Вход»/«Выход» —
  тексты раскрываются полностью, прокрутка на уровне колонки модалки; «Причина добавления»
  и ранее выводилась целиком, теперь и данные не усекаются.
- Реструктуризация `/docs`: плоские PRD.md / ADR.md / FR.md / CR.md →
  `docs/{prd,adr,fr,cr}/`: в каждой папке `index.md` (таблица: id, тема, статус, правила
  ведения), каждый документ — отдельный файл (`ADR-007-auto-manual-decision-modes.md`,
  `FR-400-decisions.md`, `CR-003-decision-branches.md`…); сводка стека вынесена в
  `adr/tech-stack.md`; корневой `docs/README.md` — карта документации + конвенции
  именования/нумерации/статусов для агентной разработки.
- Новые артефакты документации: FR-309 (полные тексты), этот CR-005, обновление ADR-005,
  PRD v0.4 (разделы-ссылки на новую структуру).

**Результат.**
- Вход/Выход/Причина выводятся полностью: E2E на свежем прогоне — «Вход» 505 симв. и
  «Выход» 395 симв. отображаются целиком (`max-height: none`, scrollHeight == clientHeight),
  в новых прогонах 0 многоточий во входах (было до 3 на прогон); консоль 0/0, lint чист.
- Тесты: `test-tacg-decision` — все сценарии; `test-tacg-clarity` — 17/17.
- `/docs` — 4 типовых папки с индексами, 26 файлов; навигация для агентов: docs/README.md →
  index папки → отдельный документ.
