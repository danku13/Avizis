# CR-013 — Обход гейта OpenRouter + мгновенная обратная связь запуска

> Дата: 2026-10-12 · Связанное: [ADR-020](../adr/ADR-020-openrouter-agentic-gate.md), [ADR-012](../adr/ADR-012-byok-llm-router.md), [FR-911](../fr/FR-900-byok.md), [ADR-003](../adr/ADR-003-event-sourcing-fold.md)

## Мотивация (цитаты запроса)

> «надо заставить работать thinkingmachines/inkling:free, сейчас он падает т.к. говорит что
> работает только с агентными приложениями.»

> «сейчас при запуске агента история запусков не обновляется и TACG не переключает на новый
> запуск агента из-за чего кажется что ничего не запустилось»

## Что сделано

1. **Обход гейта** (ADR-020): общий клиент `openai-client.ts` — авто-детект ошибки
   «agentic harnesses» (403-тело или `error` в 200) → один повтор с tools
   (`submit_final_answer`, без `tool_choice`) → кэш per `(baseUrl|model)`;
   `extractMessageContent` разворачивает `tool_calls` (answer/result/output/сырая строка,
   мультивызовы склеиваются); адаптер llm.ts и `validateProvider` используют общий клиент —
   настройки inkling:free сохраняются.
2. **4xx без ретраев**: `NonRetryableProviderError` для 401/402/403/404/… — ретраи уровня llm.ts
   пропускаются мгновенно (408/429/5xx остаются транзиентными).
3. **Мгновенная история**: движок сохраняет прогон в store и транслирует `history:list` при создании
   прогона (после `run:created`), не только по терминальному статусу.
4. **Оптимистичный фронт**: `onRunCreated` вставляет запись прогона в историю сразу (статус
   «планирование», пульсирующая точка); `applyEvent` живьём обновляет статус/прогресс/число
   узлов записи текущего прогона.
5. **Видимое планирование**: пустой граф при живом прогоне показывает «Агент работает…»
   (пульсирующий индикатор + подпись) вместо пустого полотна.
6. **Тост ошибки прогона**: `run:status{status:error,reason}` → toast с причиной (событие
   пополнилось опциональным `reason`; бейдж режима показывает реальную модель прогона вместо
   «z-ai-web-dev-sdk», в MD-отчёте — тоже).
