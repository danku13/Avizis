# CR-010 — Сворачиваемый журнал и компактная шапка

> Тип: change request · Дата: 2026-10-12 · Связанное: [FR-708](../fr/FR-700-nfr.md),
> [FR-602](../fr/FR-600-history-and-log.md), [FR-906](../fr/FR-900-byok.md), [CR-002](../cr/CR-002-fullwidth-reactflow-inspector-modal.md)

## Мотивация (цитата запроса)

> «нужно сделать "Журнал событий" сворачиваемым, чтобы максимизировать размер графа выполнения,
> так же надо эффективнее использовать шапку сайта, сейчас она занимает много места, но из
> эффективного там только статус "движок агента" и переключение тёмного/светлого стиля»

Граф выполнения — главный элемент экрана, но вертикальный бюджет съедали две постоянные
величины: журнал фиксированной высоты (260px, всегда виден) и двухстрочная шапка (~61px) с
декоративным подзаголовком. При этом LLM-чип (BYOK) занимал строку в тулбаре прогона, хотя
настройка провайдера — глобальная, а не свойство конкретного прогона.

## Изменения

### 1. Сворачиваемый журнал событий (FR-708)

- `event-log.tsx`: контейнер журнала владеет своей высотой сам (обёртка из `page.tsx` убрана):
  развёрнут — `h-[260px]`, свёрнут — `h-11`; плавная анимация высоты
  (`transition-[height] duration-200`, `motion-reduce:transition-none`), `overflow-hidden`.
- Вся строка заголовка — кнопка-переключатель (зона клика 44px = a11y-таргет):
  `aria-expanded`/`aria-controls`, `title`-подсказки «Развернуть/Свернуть — освободить место
  под граф», chevron с поворотом −90°.
- Состояние — во внешнем хранилище `localStorage 'tacg-log-collapsed'` через
  `useSyncExternalStore` (как тема в `theme.ts`): SSR-снимок false согласован с серверным HTML,
  после гидратации синхронизируется без setState-в-эффекте (react-hooks/set-state-in-effect
  ловится линтером); дефолт — развёрнут, выбор переживает перезагрузку.
- Свёрнутый вид информативен: бейдж live/кадр, счётчик записей и превью последней записи
  (`[вид] сообщение`, только ≥md) — информация не теряется, новые live-события видны по
  счётчику; тело (`ScrollArea`) остаётся в DOM (нулевая высота + `aria-hidden`) — анимация
  без перемонтирования.
- Свёрнутый журнал отдаёт графу ровно 216px (260−44): канва 241 → 457px на стенде 900px
  (замер E2E).

### 2. Компактная шапка (FR-708)

- `page.tsx`: одна строка `h-11` (было ~61px): лого `size-6`, заголовок `text-sm`, статус
  движка, чип LLM, тема. Подзаголовок «Transparent Agent Computation Graph…» удалён как
  неэффективный (по мотивации запроса); статус движка — компактный чип `h-7`
  («движок: подключён» / «движок: офлайн», на <sm — только иконка), `role="status"` +
  `aria-label` сохранены.
- **LlmChip перенесён из тулбара в шапку** (новый файл `llm-chip.tsx`, компактные размеры
  `h-7`/`size-7`): провайдер+модель и шестерёнка настроек BYOK — глобальные, теперь доступны
  всегда, а тулбар прогона отдаёт строку данным прогона (в состоянии «нет прогона» — только
  подсказка «задайте задачу»).
- `theme-toggle.tsx`: кнопка `size-7` (иконка `size-3.5`) под компактную шапку.

## Результат (верифицировано)

- Шапка: **45px** против ~61px (замер boundingBox E2E); подзаголовка нет, статусы
  («LLM: z-ai SDK», «движок: подключён») и переключатель темы на месте.
- Журнал: свёрнут — **44px**; канва на стенде 1440×900 при загруженном 9-узловом прогоне
  **241 → 457px** (+216 = 260−44, ровно); разворачивание возвращает 260px; счётчик записей
  (15) и превью `[решение] Режим «ручной выбор»…` видны в свёрнутом виде.
- Персистентность: `localStorage tacg-log-collapsed` = 1/0, переживает reload; после reload
  с сохранённым «свёрнут» — консоль чистая (нет предупреждений гидратации).
- Консоль чистая на всех шагах (0 ошибок/0 предупреждений), включая сворачивание/разворачивание
  и resize канвы — React Flow warning 004 («parent container needs a width and a height»)
  при сворачивании не возникает (канва только растёт).
- Мобильная 390×844: без горизонтального скролла, шапка 45px помещается, свёрнутый журнал 44px,
  клик-таргет работает; VLM-проверка скриншотов — дефектов вёрстки нет.
- Регрессии: `test-tacg-clarity` 17/17, `test-tacg-decision` — все сценарии, `test-tacg-byok`
  13/13, `test-tacg-usage` 13/13; `bun run lint` — чисто; `tsc` — 30 ошибок = базовый уровень
  (проверено stash-сравнением: до правок 30 / после 30, все — преждесуществующие в
  graph-canvas/скриптах/скиллах).
