# CR-009 — Токены, светлая тема и разведение цветов графа

> Тип: change request · Дата: 2026-10-12 · Связанное: [ADR-015](../adr/ADR-015-token-usage.md),
> [FR-605](../fr/FR-600-history-and-log.md), [FR-706/707](../fr/FR-700-nfr.md), [FR-204](../fr/FR-200-live-graph.md)

## Мотивация (цитаты запроса)

> «Не вижу чтобы сейчас в аудите или где-то в интерфейсе выводилась информация о количестве

> «И добавь светлый стиль. Цвет для "добавлено динамически" и "развилка решения" слишком
> одинаковые цвета, нужно более разные цвета относительно остальных и между ними.»

> «Сформируй отдельный документ в /docs по продуктовым возможностям и гипотезам относительно
> рынка и самого продукта, сформируй value proposition map и перечень из 4 ЦА на которые можно
> ориентироваться»

## Изменения

### 1. Аудит использования токенов (ADR-015)

- `llm.ts`: `extractUsage` (OpenAI `prompt_tokens`/`completion_tokens` и GLM
  `input_tokens`/`output_tokens`), usage у zai- и openai-compatible-адаптеров;
  `chatTextDetailed`/`chatJsonDetailed` → `{ content/json, usage }` (JSON-usage копится по
  попыткам); старые функции — обёртки.
- `types.ts` ×2 (зеркало): `NodeUsage` (в `GraphNode.usage`), `RunUsage` (в
  `RunSnapshot.usage`/`RunView.usage`), событие `llm:usage` (`role`, `nodeId?`, `inputTokens`,
  `outputTokens`), `fmtTokens`.
- `engine.ts`: `addUsage` — сводка снапшота + атрибуция узлу + событие. Исполнитель — узлу до
  финального `node:update`; решатель — узлу-развилке; планировщик/супервайзер — только в сводку.
  Хвосты «· токены: ↑N / ↓M» в журнале шагов/плана; итог в финальной записи, summary и записи
  остановки.
- `fold.ts`: аккумуляция `llm:usage` → `RunView.usage` (totals + byRole + calls) и `node.usage`;
  работает в live и до курсора (replay).
- UI: чип «↑ … · ↓ … · N вызов.» в тулбаре с тултипом по ролям (live и replay); строка
  «Токены: ↑ / ↓» в мета-гриде инспектора; в MD-отчёте — секция «## Использование токенов»
  (таблица ролей + итог) и колонка «Токены ↑/↓» в таблице графа.

### 2. Светлая тема (FR-706)

- `layout.tsx`: bootstrap-скрипт в `<head>` выставляет класс `.dark` до гидрации
  (localStorage `tacg-theme`, отсутствие записи → тёмная); статический класс с `<html>` снят —
  нет всплеска и рассинхрона гидрации.
- `src/lib/tacg/theme.ts` (новый): `useIsDark` (useSyncExternalStore, SSR-снимок — тёмная),
  `toggleTheme` (класс + localStorage + уведомление подписчиков).
- `theme-toggle.tsx` (новый): Sun/Moon в шапке.
- Все TACG-компоненты (page, graph-canvas, node-inspector, run-toolbar, decision-modal,
  settings-modal, event-log, history-panel, timeline, status-badge): light-варианты через
  `dark:`-префиксы (фоны/тексты/бордеры/акценты 600↔300).
- `globals.css`: React Flow Controls/MiniMap/атрибуция и скроллбары — светлая база +
  `.dark`-переопределения; MiniMap/фон-точки/базовые цвета рёбер — от `useIsDark`.

### 3. Разведение цветов (FR-204, FR-707)

- **Развилка решения: fuchsia → amber** («ваш ход»): рамка/пульсация/полоска/иконка/статусные
  строки карточки-развилки, рёбра ветвей, баннер ожидания, бейджи инспектора, акценты
  модалки выбора, чип «ждёт уточнений», [решение] в журнале. Гашёные ветки — emerald/серый
  пунктир как раньше.
- **«Ожидает» (pending): amber → нейтральный цинк** (план-«чертёж» оживает цветом), амбер
  освобождён под развилки; легенда и статусные точки обновлены.
- **«Добавлено динамически» — violet без изменений** (максимальный контраст с amber: тёплый ↔
  холодный); violet-рёбра динамики чуть ярче (0.75).
- MiniMap: развилка `#f59e0b`, pending `#a1a1aa`, skipped `#71717a`.

### 4. Продуктовый документ

- `docs/product/PRODUCT-001-capabilities-market.md` (новый тип документов + индекс):
  инвентаризация возможностей прототипа и честные ограничения; 10 фальсифицируемых гипотез
  (6 рынка H1–H6, 4 продукта H7–H10) с метриками и опровержениями; value proposition map
  (круг ценности / профиль клиента / соответствие «боль → болеутолитель → выгода» / УТП);
  4 сегмента ЦА (С1 инженеры — ядро, С2 продакты, С3 консультанты — ранний доход, С4 образование
  — вирус) с профилями и сравнительной таблицей.
