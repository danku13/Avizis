## Назначение папки

Продуктово-рыночные документы: инвентаризация возможностей, гипотезы рынка и продукта,
value proposition map, целевые сегменты (ЦА), позиционирование. Отдельный тип от PRD:
PRD отвечает «что строим и зачем для пользователя», PRODUCT — «что это значит для рынка,
кого и как мы завоёвываем».

## Правила ведения

- Один документ — один файл, префикс `PRODUCT-NNN`, нумерация сквозная.
- Гипотезы фальсифицируемы: формулировка → проверка → метрика → опровержение.
- По результатам проверок гипотеза получает статус (подтверждена / опровергнута / уточнена)
  со ссылкой на CR.
- Связи: возможности → [../fr/](../fr/index.md), решения → [../adr/](../adr/index.md),
  продукт → [../prd/PRD.md](../prd/PRD.md).
